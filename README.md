# 散修宗投资大脑

本地、财务分析优先的投资研究软件。它把法定财报与公告、确定性财务计算、用户导入的投资流派资料、个人持仓以及 Codex/OpenAI 兼容 API 分层处理。

## 当前第一版

- 财务驾驶舱：盈利能力、现金质量、资产负债、治理审计、估值。
- 确定性指标：TTM、杜邦、ROIC、自由现金流、营运资本、偿债和财务红旗。
- 估值工作台：DCF 三情景、3×3 敏感性矩阵、反向 DCF、DDM 与 PE/PB 相对估值；可编辑增长率、折现率、永续增长、预测期、倍数锚点和安全边际。各方法独立显示价值区间及安全边际后区间，不强行平均；财务期、价格日和分析截止日分开展示。每次运行保存假设、结果与数据指纹，公式可追踪。
- 银行专用模型：识别 Tushare `comp_type=2`，独立计算净息差、不良/关注/逾期、拨备、贷存比、ROE 与资本充足指标；缺失监管披露不会当作正常。支持带报告名称、链接和页码的人工补录（生成新快照而非覆盖原数据），以及 PB/剩余收益三情景、安全边际和估值历史；工业企业 DCF、净债务和通用 FCF 指标对银行保持禁用。
- 周期资源、公用事业与地产插件：根据行业或显式模板路由到独立财务口径。周期资源按产销量、实现价格、单位现金成本、储量寿命、维持性资本开支计算中周期盈利和储量 NAV；公用事业按装机、利用小时、电价、燃料成本、受监管资产和允许回报计算受监管盈利与 DDM；地产按合同负债、销售回款、受限资金、项目存货减值、短债和担保分析流动性，并用显式存货折价与合同结转假设计算调整 NAV/PB。行业披露可连同报告名称、链接、页码补录，原快照不会被覆盖；缺失指标不会拿通用利润率代替。
- 保险与券商插件：保险按保险服务收入、保费、新业务价值、内含价值、投资收益、保险合同负债及核心/综合偿付能力分析，并分别显示 P/EV 与 EV+NBV 评估价值；券商按经纪、投行、资管、自营、利息收入、净资本及四项风险控制指标分析，并分别显示 PB 与正常化盈利 PE。偿付能力和证券风控最低线来自金融监管总局、证监会现行公开规则，报告保留规则名称、链接与披露期；缺少风险综合评级或监管口径数据时不得声称合规。
- 知识流派审核台：扫描 DOCX/PDF/Markdown/TXT、哈希去重和 SQLite 全文检索；可从指定流派文档批量生成带原文段落定位的待审核规则，结构化保存适用行业、周期、财务指标、阈值、成立条件、例外和反方证据。候选规则不会自动启用，每次编辑、审核和启停都有版本快照。
- 多流派分析：只把“已审核且启用”的规则送入 Codex/兼容 API；证据包按流派独立分组，并显示不同体系间的启发式共识/冲突线索。模型必须逐个体系形成结论后再讨论关系，不能把红利、格雷厄姆、散修宗等观点混成平均结论。
- 持仓：成本、数量、期限、最大承受损失和买入逻辑。
- 观察清单：本地持久化、真实行情快照刷新、PE/PB/截至日期与旧数据标记。
- 公司对比：2–4 家公司使用同一 TTM 口径横向比较，缺失和跨行业风险明确提示。
- 财报证据仓：从巨潮按股票与日期查询关键财报、审计、更正和问询文件，或导入官方 PDF 直链及本地副本；原件按 SHA-256 归档，关键词线索可回到 PDF 页码。
- 排雷覆盖矩阵：审计意见、关键审计事项、应收账龄、存货/商誉减值、关联交易、担保、受限资金、非经常损益、资本化、会计更正和监管问询逐项显示“已确认/待复核/已排除/文本未命中/不可检索”。
- 财务变化检测：程序比较可比 FY/TTM，识别利润现金背离、周转恶化、净负债与偿债压力、分红覆盖、资本开支挤压和连续三期恶化；每条变化可展开公式与原始来源。
- 持仓决策循环：将成本、最大承受亏损、仓位集中度、财务红黄旗和变化信号合并为“立即复核/条件复核/继续观察”行动清单，不自动交易。
- 持仓导入：支持粘贴 CSV，中文列名可直接识别；错误行会单独报告，不会静默写入。
- AI：Codex CLI 与 OpenAI Chat Completions 兼容接口；不会静默切换收费渠道。
- 可复现报告与复盘：AI 分析成功后冻结证据全文、数据截至日、财务引擎、模型、规则版本和输入指纹；研究档案支持同一股票跨日期确定性指标/规则版本差异、证据快照和“预期条件—实际结果—下次复核日期”记录。

目前已支持 A 股一般非金融企业、银行、周期资源、公用事业、房地产开发、保险和券商的独立财务模板。所有已识别的金融行业都会停止通用工业模型，不能套用工业企业自由现金流 DCF。

## 本地运行

1. 双击 `start.bat`，它会启动本地数据服务和软件界面。
2. 默认浏览器会打开 `http://localhost:3000`；数据服务固定为 `http://127.0.0.1:8765`。
3. 首次在“知识库”中扫描当前资料目录。
4. 为资料建立投资体系，在规则审核台选择一个体系，点击“从该体系文档生成候选”；逐条回看原文并通过后，规则才会参与分析。

首次使用免费 A 股数据时可双击 `setup-free-data.bat` 安装 AKShare 与 BaoStock；安装完成后重新运行 `start.bat`。启动脚本会优先使用 Codex 附带的 Python，避免把依赖安装到一个 Python、运行时却选中另一个 Python。

扫描版或字符映射异常的财报可双击 `setup-ocr.bat` 安装本地中文 OCR。证据仓会先检查 PDF 文本层可读性；不可读时不会把“零命中”解释为没有风险。选择公告后点击“OCR 下一批”，系统每次在本机处理 8 页并保存进度，整份完成前始终标注为部分覆盖。

运行需要 Python 3、Node.js 和 pnpm。当前电脑可直接使用 Codex 附带的运行环境；复制到其他电脑时，请先安装这三项。关闭前端命令窗口后界面服务会停止；后台数据服务可在任务管理器中结束对应的 Python 进程。

日常启动使用 `start.bat`，它会启动带本地 Worker API 代理的开发服务，确保页面能访问 `127.0.0.1:8765` 财务后端；不会自动重装依赖。需要验证生产构建时，再运行 `pnpm run build && pnpm run start`。

## API Key

兼容 API 的密钥只从 `INVESTMENT_BRAIN_API_KEY` 环境变量读取，不写入数据库。Base URL 和模型名可在软件中保存。Codex 模式调用本机 Codex CLI，并沿用它自己的官方登录状态。

A 股数据现在采用“免费优先、Tushare 可选”：未配置 `TUSHARE_TOKEN` 时，软件会尝试 AKShare（公开财务报表/行情），并用 BaoStock 做历史行情和部分数据回退；配置 Tushare 后优先使用 Tushare Pro。免费源的结果会标记为 provisional，并保存来源、更新时间和警告。可用 `requirements-free.txt` 安装两个可选依赖。Token 同样不会写入数据库或报告；拉取结果会以带来源信息的本地快照缓存。当前 Tushare provider 支持一般企业及 `comp_type=2/3/4` 的银行、保险、证券基础报表；周期资源、公用事业、地产、保险和券商的专用经营/监管指标仍需从法定披露补录。

## 当前数据边界

软件已具备财务标准化、指标/估值计算、文档知识库、持仓、Tushare BYOK 和双 AI 引擎。界面中的静态公司卡片仍明确标为演示；配置 `TUSHARE_TOKEN` 后，分析任务会拉取并计算真实三表，在未配置时则阻止把虚构演示数字套到真实股票。关键结论仍应以交易所/巨潮公告原文复核。

“财报证据”页面中的自动查询使用巨潮公开公告目录，仅用于个人本地、低频研究。它不是商业数据授权或可用性承诺。公告关键词命中只是待复核线索，不等同于公司存在造假；覆盖矩阵中的“文本未命中”也不代表事项不存在，扫描版 PDF 会明确标记需要 OCR。

## 数据原则

- 原始资料只读，软件不会删除或改写源文件。
- 0、缺失、未披露与不适用严格区分。
- 每个财务事实保存报告期、披露日、口径、单位和来源定位。
- 勾稽失败或数据不足时停止精确估值，AI 不得补猜。
- 报告区分法定事实、系统计算、文档观点和 AI 推断。
- 报告历史保留当时证据快照；后续财务重述或知识规则编辑不会静默改写旧报告。旧版本报告若只有早期哈希而没有快照，会明确标记为旧报告，不能声称可完整复现。
